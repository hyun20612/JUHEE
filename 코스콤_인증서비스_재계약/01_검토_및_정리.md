## 1. 총무부 교육자료 검토 (「전사 계약 프로세스 등 관련 업무 교육자료」, 총무부 총무팀, 2026.8.3.)

### 1-1. 핵심 내용 요약

**기본 방향**
- 사업자 선정·계약방법 결정은 **계약담당부서(총무부)** 권한
- 사업부서는 요청사항(선호방식)을 적시하는 구조로 변경

**계약의뢰 프로세스**

| 단계 | 수행부서 | 내용 | 비고 |
|---|---|---|---|
| ① 기본방안 수립 | 사업부서 | 계약 관련 사항은 "총무부가 정함"으로 기재 + 사업부서 선호방식 적시 | 일상감사 6호 |
| ② 계약체결 의뢰 | 사업부서 | ❶계약체결 의뢰(안) ❷기본방안(원인행위 문서) ❸제반서류 첨부 | 예산금액 확인 |
| ③ 계약방식 결정 | 총무부 | 10억 이상 계약심의위원회 / 10억 미만 총무부 결정 | 일상감사 9호 |
| ④ 계약절차 진행 | 총무부 | 필요시 사업부서에 자료 추가 요청 | |

**수의계약 의뢰 시 필요서류**: 계약체결 의뢰(안)(목적·수량·기간·예상소요비용·예산과목 포함), 기본방안, 견적서·사업자등록증·용역내역서(과업지시서) 등, **수의계약사유서(근거조항 명시 필수)**

**기타 유의사항**
- 계약의뢰 전 총무부 담당자와 **사전협의 권고**
- 의뢰 시점: 3백만~2천만원 → 2주 前 / **2천만원 이상 → 8~12주 前** (영업일 기준)
- 계약 전 사업부서가 업체와 계약내용 이행 금지(**先발주 금지**)
- 일상감사 대상 건은 **반드시 일상감사 후 계약의뢰**, 일상감사 결재문서와 **다른 내용으로 의뢰 불가**
- 2장(제안서 평가지침 개정, '26.6.17 시행)·3장(기술능력평가)은 **입찰 건 대상** → 본 건(수의계약)은 직접 해당 없음. 단, 총무부가 입찰로 결정할 경우 적용됨

**교육 시 필기 메모(사진 내 손글씨)**
- 사업예산은 6호 일상감사에서 받은 금액과 **동일하게**
- 납품기한은 정확히 기재, 조정 가능하면 "변동가능" 명시 → OCSP 실적정산 문구 필요
- 첨부: 과업지시서(1장 정도, 샘플 요청 가능) / 기본방안 / 견적서
- **수의계약사유서 → 5천만원 이상은 대부분 입찰** ← 본 건(약 8천만원) 사유서 보강 필요

### 1-2. 작년 방식과 비교한 이번 재계약 시 반영 포인트

| # | 작년(2025.12) 방식 | 교육자료 기준 이번에 할 것 |
|---|---|---|
| 1 | 체결방안(일상감사, 6903)과 체결의뢰(6921)를 **같은 날(12.5)** 시행 | 일상감사 결재 **완료 후** 의뢰 (메모상 순서: 감사부 OK → 체결방안 상신 → 총무부 OK → 의뢰) |
| 2 | 11.28 의뢰 → 12.5 시행 → 12.29 체결통보 (계약개시 약 4주 전) | **11.5 이전 의뢰** 목표 (8주 前) |
| 3 | 1차본 "계약방법: 총무부가 결정" → 총무부 요청으로 "수의계약 및 1인 견적서"로 수정 | 두 가지를 **모두** 기재: "계약방법 등은 계약담당부서가 정함" + "(사업부서 선호방식) 수의계약 *[별첨] 수의계약사유서" |
| 4 | 수의계약사유서는 총무부 요청 후 사후 추가 | 처음부터 첨부, 근거조항(§47①1 자목) 명시 |
| 5 | 사유서 근거: 시스템 재구축 필요·업무불편 (정성적) | 5천만원 이상 입찰 원칙 대응 위해 **정량 근거 보강** 권장(재구축 예상비용, 대체 인증사업자 적용 시 영향 범위, 발급 인증서 수 등) |
| 6 | OCSP 확정금액 대기로 의뢰 지연 | OCSP는 "실적정산·변동가능" 명시하고 **추정치로 먼저 진행** (11.18 메일에서도 이미 같은 판단) |
| 7 | 과업지시서 별도 없음 | 과업지시서(1장) 첨부 요구 가능성 → 총무부에 사전 확인 |

## 5. 확인 필요 / 리스크

1. **일정**: 교육자료 기준 의뢰 권고시점(8~12주 前)에 이미 진입. 11월 초 의뢰 못하면 총무부에 사전 양해 필요
2. **수의계약 정당성**: 5천만원 이상은 입찰이 원칙이라는 총무부 언급 → 사유서에 정량 근거 추가 권장. 입찰로 결정될 경우 제안서 평가지침(기술 70/가격 30 등) 적용됨
3. **근거조항 일관성**: 2차본에서 차목→자목으로 바꿨으나, 참고자료 "4. 기타사항"에 차목 문구가 남아 있는지 원본 확인(사진상 판독 불가)
4. **연도 표기 혼선**: 문서 제목 "'25년 계약"은 2026년 이용분이고, 메모의 "2024년계약"은 2024년 이용분 의미 → 올해 문서는 "**'27년(이용) 인증서비스…**"처럼 이용연도 기준으로 통일 권장
5. **'25 이용금액 수치 불일치**: 1차본 77,756,620 vs 2차본 77,749,570 – 근거(11월 OCSP 반영 방식) 확인
6. **자동연장 조항(§3)**: 매년 재계약 중이나 자동연장 조항 존재 → 총무부가 "자동연장으로 갈음 가능" 여부를 물을 수 있음
7. **계약서 갱신 항목**: 계약일·기간, 대표자(갑·을), 수량·금액, 계약보증금(10%), 재위탁사(아이티네이드) 변경 여부, 개인정보 관련 법령 개정 반영
8. **예산 배정액**: 작년 1차본에서 배정액 오기재 → 올해는 2027 예산신청내역으로 먼저 확인
